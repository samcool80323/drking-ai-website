# DrKing.ai Website

42-page marketing site for DrKing — AI-powered patient communication platform for Australian medical clinics.

## Tech Stack
- Static HTML/CSS/JS (no build step)
- Cloudflare Pages hosting
- Geomanist (sans) + Newsreader (serif) fonts
- Organic "Living Organism" design system

## Deploy
Push to `master` → GitHub Actions auto-deploys to Cloudflare Pages → live on drking.ai

## Structure
- `index.html` — Homepage
- `*.html` — 41 sub-pages (industries, problems, solutions, comparisons, resources, legal)
- `fonts/` — Geomanist woff2 files
- `drking-logo.svg` — Brand logo
- `sitemap.xml` — XML sitemap
- `robots.txt` — Robot directives
